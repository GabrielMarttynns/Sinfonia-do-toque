# 🎮 Color Motion

## 📌 Sobre o Projeto

O **Color Motion** é um jogo interativo desenvolvido como projeto acadêmico, com foco no estímulo da coordenação motora, agilidade e capacidade de percepção visual por meio de uma experiência gamificada.

O jogo utiliza três cores diferentes, três botões físicos e luzes de LED. O objetivo é fazer com que o jogador identifique a cor que está acesa e pressione o botão correspondente.

## 🎯 Objetivo

Desenvolver um jogo que estimule a coordenação motora, o tempo de reação e a percepção visual do jogador, utilizando dispositivos IoT para tornar a interação física parte da experiência.

## 🕹️ Como funciona o jogo?

O Color Motion funciona de maneira simples e interativa:

1. Uma das três luzes de LED é acesa.
2. O jogador identifica qual cor está iluminada.
3. O jogador pressiona o botão correspondente àquela cor.
4. O sistema verifica se a resposta está correta.
5. A pontuação é atualizada de acordo com os acertos e o desempenho do jogador.

Cada botão representa uma cor específica, permitindo que o jogador interaja diretamente com o jogo por meio dos dispositivos físicos.

## 🌈 Sistema de Cores

O jogo possui três cores diferentes, cada uma associada a um botão físico:

- 🔴 Botão vermelho: corresponde ao LED vermelho.
- 🟢 Botão verde: corresponde ao LED verde.
- 🔵 Botão azul: corresponde ao LED azul.

## 🏆 Fases do Jogo

O jogo contará com três fases de dificuldade progressiva:

**Fase 1 – Fácil:** apresenta sequências mais simples, com maior tempo para identificar e pressionar a cor correta.

**Fase 2 – Intermediária:** aumenta a velocidade das luzes e exige respostas mais rápidas.

**Fase 3 – Difícil:** apresenta desafios mais rápidos, exigindo maior concentração, agilidade e precisão.

## 📊 Sistema de Pontuação

O desempenho do jogador será avaliado considerando:

- Quantidade de acertos.
- Quantidade de erros.
- Tempo de reação.
- Precisão das respostas.
- Evolução do desempenho entre as fases.

## ⚙️ Tecnologias Utilizadas

- **Java:** linguagem de programação.
- **libGDX:** framework utilizado para desenvolver o jogo.
- **IoT:** integração com LEDs e botões físicos.
- **GitHub:** armazenamento e controle de versão do projeto.

## 🎓 Finalidade Acadêmica

O Color Motion faz parte de um projeto acadêmico que busca demonstrar como a tecnologia e a gamificação podem ser utilizadas como ferramentas de apoio à reabilitação física, estimulando movimentos, coordenação motora, percepção visual e tempo de reação.
